Hubungkan dengan GitHub Personal Access Token untuk menambah, mengedit, menghapus proyek, dan mengunggah gambar thumbnail langsung ke repositori GitHub Pages.

Pengaturan Repositori (Default: aduyngrh/portofolio)
Cara membuat Token GitHub dalam 30 detik
  1. Buka halaman Fine-grained Personal Access Tokens di GitHub.
  2. Isi Token name (mis. Portofolio CMS) dan pilih masa berlaku.
  3. Pada Repository access, pilih Only select repositories → pilih portofolio.
  4. Buka Permissions → Repository permissions, ubah Contents menjadi Read and write.
  5. Klik Generate token, lalu salin dan tempel di kolom atas.
