# Portofolio Yudha

Website portofolio pribadi untuk menampilkan profil, keahlian, pengalaman, dan proyek yang pernah dikerjakan Yudha sebagai Full-Stack Developer dan UI/UX Designer.

## Fitur

- Tampilan responsif untuk desktop dan perangkat mobile.
- Dark mode dan light mode.
- Preferensi tema tersimpan di `localStorage`.
- Navigasi mobile.
- Animasi typewriter pada bagian hero.
- Filter proyek berdasarkan kategori.
- Modal detail proyek.
- Command palette untuk navigasi cepat.
- Resume/CV dengan opsi cetak atau simpan sebagai PDF.
- Live playground untuk mencoba beberapa properti CSS.
- Efek suara opsional menggunakan Web Audio API.
- Tombol salin email dan tautan WhatsApp.
- Scroll progress dan tombol kembali ke atas.
- Data profil dan proyek terpusat di `js/projects-data.js`.

## Teknologi

- HTML5
- CSS3
- JavaScript
- Node.js native HTTP server
- Web Audio API
- HTML5 Canvas
